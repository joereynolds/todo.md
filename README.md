## How it works

Point it at a directory and it'll slurp up all `.md` recursively in that directory.

It'll find any tasks that follow the github flavoured markdown task format (with a few extensions by yours truly).

A few examples

```
- [ ] An incomplete task
- [ ] An incomplete task that is due on christmas !2026-12-25
- [-] A cancelled task
- [x] A completed task
- [ ] A task that can be done in roughly 5 minutes ~5m
```
